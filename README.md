# Custom AI Agent Makers & HR MIS Solutions

[![Three.js](https://img.shields.io/badge/Three.js-3D-purple)](https://threejs.org)

An immersive, VFX-powered landing page for **Custom AI Agent Makers & HR MIS Solutions** — a next-generation enterprise specializing in autonomous AI agents, LLM integrations, and intelligent HR Management Information Systems.

## ✨ Features

- **3D Particle Field** — GPU-accelerated interactive particle system built with Three.js
- **Interactive Cursor Trail** — Custom cursor with trailing glow effects
- **Scroll-Triggered Animations** — GSAP + ScrollTrigger for smooth section reveals and parallax
- **SVG Morphing** — Animated background path layer with fluid transitions
- **Responsive Design** — Fully adaptive across desktop, tablet, and mobile
- **Dark Cyber-Aesthetic** — Dark theme with electric blue/cyan/neon accents
- **Animated Counters** — GSAP-powered number counters in the About section
- **Glitch Text Effects** — Subtle glitch animation on the hero headline

## 🎨 Tech Stack

| Technology | Purpose |
|---|:---|
| **Three.js** | GPU-accelerated 3D particle background |
| **GSAP** | Scroll-triggered animations, parallax, counters, path morphing |
| **HTML5 / CSS3** | Semantic structure, responsive layouts, custom properties |
| **Canvas API** | Sprite texture generation for particles |

## 🚀 Sections

1. **Hero** — Full-screen particle field with animated gradient headline
2. **Services** — Six service cards with hover glow effects
3. **About** — Company story with animated stats counters
4. **Contact** — Contact form and information panel
